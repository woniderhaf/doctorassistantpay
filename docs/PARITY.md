# Чек-лист паритета с iOS-приложением

Веб-версия (`doctorAssistantPay-web`) повторяет поведение iOS-приложения
(`doctorAssistantPay`). Расчётное ядро портировано 1:1 и покрыто тестами
(`src/core/__tests__`, порт `PayCalcCoreTests`). Этот список — для ручного
прогона рядом с открытым iOS-приложением.

## Расчёт (тестируется автотестами, сверять не нужно)

- [x] Округление до ближайшего получаса: 6 ч 40 мин → 6,5 ч; 6 ч 50 мин → 7 ч;
      15 мин → 0,5 ч; 45 мин → 1 ч; 14 мин → 0 ч; 0/отрицательное → 0 ч.
- [x] Ручная сумма (overridePay) важнее авторасчёта; в списке — оранжевый карандаш.
- [x] closeShift: начало = фактическое (иначе плановое); end ≤ start ⇒ end = start + 60 с
      (тогда округлится в 0 ч — в iOS ровно так же, не «чиним»).
- [x] Плановые смены не попадают в зарплату, пока не закрыты.

## Строки и форматы (открыть оба приложения на одном экране)

- [ ] Деньги: «12 600 ₽» (неразрывный пробел, до двух знаков: «400,5 ₽»).
- [ ] Часы: «6,5 ч», «7 ч».
- [ ] Заголовок дня: «12 октября, понедельник» (день впереди,weekday со строчной).
- [ ] Месяц: «Октябрь 2026» — без « г.».
- [ ] Плюрализация: 1 запись / 2 записи / 5 записей.

## Календарь

- [ ] Понедельник первый; зелёная цифра дня с записями; синяя точка плановой смены;
      кольцо на «сегодня»; залитый синий круг на выбранном дне; кнопка «Сегодня».
- [ ] Плашка «Смена началась?» (оранжевая) появляется сама, без перезагрузки, ≤30 с
      после планового начала; «Да, началась» → зелёная «Активная смена» с временем старта.
- [ ] «Завершить смену» создаёт запись за день начала смены и убирает смену из плана.
- [ ] Секция «Запланировано» — только плановые (не активные) смены выбранного дня.
- [ ] Итог дня в подвале списка; пустой день — «Нет записей за этот день».

## Форма записи

- [ ] Дефолты новой: 9:00–17:00, ставка из настроек.
- [ ] end ≤ start ⇒ окончание переносится на следующий день.
- [ ] Превью «Отработано (округлено)» меняется на лету.
- [ ] Пустая/мусорная ставка → расчёт по ставке из настроек (как iOS-фолбэк).
- [ ] Создание новой записи запоминает введённую ставку как новую по умолчанию.
- [ ] duration-запись: степперы 0–23 ч, 0–55 мин шагом 5; в списке «8 ч» / «8 ч 15 мин».
- [ ] Ручная сумма: toggle + поле, «К выплате» = ручная, если включена.

## Форма плановой смены

- [ ] Новая: дата = выбранный день (в iOS — тоже presetDate из «+»), 9:00–17:00,
      ставка из настроек; превью «Ожидается N ч · X ₽» и сноска про «не учитывается».
- [ ] Правка сохраняет статус (активную смену форма календаря не открывает — как в iOS).

## История / Итоги / Настройки

- [ ] История: месяцы новые сверху, сумма справа, «N записей» снизу; пустое состояние.
- [ ] Месяц: «Итого за месяц» + «Отработано часов», дни новые сверху, строка
      «N ч · заметка … сумма».
- [ ] Итоги: пресеты «Этот месяц / Последние 3 мес. / Этот год / Всё время»;
      диапазон from>to трактуется включительно в обе стороны.
- [ ] Настройки: ставка сохраняется при потере фокуса, мусор откатывается;
      текст про округление совпадает со iOS-формулировкой.

## Перенос данных

- [ ] Импорт трёх iOS-файлов (эмулятор iOS → папка Files): количество записей,
      даты (включая смену через полночь), ставки, overridePay, заметки совпадают
      с приложением; warnings показываются до подтверждения.
- [ ] Бэкап → «Скачать», сменить данные, «Восстановить из копии» → всё вернулось.

## PWA / телефон

- [ ] iPhone Safari → «На экран Домой»: иконка, standalone без адресной строки,
      статус-бар синий, вкладка не прокручивается под таб-бар (safe-area).
- [ ] Авиарежим после первого визита: приложение открывается с нуля офлайн.
- [ ] Аппаратная/жестовая «назад» закрывает форму, а не уводит с вкладки.
- [ ] Ввод с клавиатуры: поля «К выплате»/«Ставка» не перекрываются.

## Известные осознанные отличия

- Секции уведомлений и ежедневного напоминания нет (web v1) — поля reminder*
  сохраняются для round-trip с iOS-экспортом.
- Строка «Напоминание за N мин» в PlannedShiftRow не рендерится.
- Модалки — bottom sheet (моб.) / центрированный диалог (десктоп), не iOS-листы.
- Свайп-удаление записи заменено кнопкой «Удалить запись» в форме.
- DST и часы через перевод часов считаются так же, как iOS (±1 ч — это не баг порта).
